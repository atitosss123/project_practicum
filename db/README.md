# База данных проекта

Хранит и исходные данные, и всё посчитанное: матрицу непохожести, профиль силуэта,
разбиение, профили кластеров, координаты проекций и таблицу устойчивости к весам.
Любое число из [отчёта](../docs/REPORT.md) поднимается запросом, а не пересчитывается.

## Запуск

```bash
brew services start postgresql@16
createdb strains
.venv/bin/python db/load.py --create-schema
```

Проверка — восемь запросов, по одному на каждый вывод отчёта:

```bash
psql strains -f db/queries.sql
```

Строка подключения берётся из `DATABASE_URL`, по умолчанию `postgresql://localhost/strains`.

## Таблицы

| Таблица | Что хранит | Строк |
|---|---|---|
| `dataset` | Какие наборы данных загружены | 2 |
| `strain` | Штаммы и их признаки | 40 |
| `strain_truth` | Настоящая группа штамма; в расчёт не подаётся | 20 |
| `pair_distance` | Непохожесть пар: три компоненты и взвешенный итог | 380 |
| `clustering_run` | Прогон кластеризации с конкретными весами | 2 |
| `silhouette_score` | Профиль силуэта по числу кластеров | 18 |
| `cluster_assignment` | Кто в каком кластере | 40 |
| `cluster_profile` | Средние признаки по кластерам | 8 |
| `projection` | Координаты точек для графиков | 40 |
| `weight_sensitivity` | Как меняется результат при других весах | 14 |

Плюс представление `distance_matrix_full` — матрица целиком, с обеими половинами
и нулевой диагональю.

## Решения по схеме

**Источник выделения — перечисление, а не текст.** Опечатка «Soil» вместо «soil» молча
создала бы четвёртую категорию и изменила размерность кодировки, а значит и все расстояния.

**Границы признаков продублированы в ограничениях таблицы.** Те же значения, что в
валидации [src/loader.py](../src/loader.py). База — последний рубеж: данные могут попасть в
неё не только через загрузчик.

**Пара штаммов хранится один раз.** Матрица симметрична, диагональ нулевая, поэтому в
таблице только верхний треугольник: ограничение `strain_a < strain_b` делает это
невозможным нарушить. Полная матрица собирается представлением.

**Сумма весов проверяется на уровне таблицы.** Прогон с весами, не дающими единицу,
означал бы несравнимые между собой результаты.

**Плато сохраняется массивом.** Поле `is_conclusive` отвечает на вопрос «определено ли
число кластеров однозначно», а `plateau` перечисляет все неотличимые варианты. Без этого
из базы нельзя было бы узнать, что `best_k` выбран с перевесом в 0.004.
